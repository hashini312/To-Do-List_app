# 📝 Minimalist To-Do List App

A clean, elegant, and responsive To-Do List web application built from scratch using pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. 

---

## ✨ Features

- ➕ **Add & Delete Tasks:** Easily add tasks with the Enter key or the `+` button, and remove completed ones.
- ✔️ **Task Toggle:** Click to mark tasks as completed with a smooth strike-through and checkmark animation.
- 📊 **Dynamic Progress Counter:** Automatically calculates and displays completed vs total tasks.
- 💾 **Persistent Data:** Uses the browser's `LocalStorage` API to keep your tasks saved even after refreshing the page.
- 🎨 **Minimalist UI & Responsive Design:** Designed with elegant typography (`Fraunces` & `DM Sans`) and custom scrollbars.

---

## 🛠️ Built With

- **HTML5:** Semantic structure
- **CSS3:** Flexbox, custom variables, animations, and pseudo-elements
- **JavaScript (ES6):** DOM manipulation, Event listeners, and LocalStorage API
